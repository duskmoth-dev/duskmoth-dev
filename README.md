## Contribute

Reproducible bug reports, focused tests, clearer documentation, and accessibility improvements are welcome.
Read each repository's CONTRIBUTING.md and SECURITY.md before opening a pull request.
Use real commits and accurate authorship. We do not fabricate contribution activity.

## Clear limits

Private transactions do not guarantee anonymity. Sanctions checks are not full AML screening.
Public source, releases, and passing tests do not mean the application has received an independent security audit.
Mainnet transactions require explicit wallet approval and separate funded end-to-end verification.
